# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

NixOS + Home Manager dotfiles for a single machine (`marshmallow`, ASUS VivoBook M3401Q with AMD CPU/GPU). Uses flakes and is managed with `nh`.

## Applying Changes

Always build first; only switch/activate when explicitly asked.

```bash
# Build (do not switch unless asked)
nh os build
nh home build

# Remote build from git
nixos-rebuild build --flake git+ssh://git@gitlab.com/victorborzov/dotfiles.git?ref=nixos

# Format Nix files
alejandra .
```

The `NH_FLAKE` env var is set to `/home/vb/dotfiles`, so `nh` commands pick it up automatically.

## Architecture

```
flake.nix                  # Entry point: defines nixosConfigurations.marshmallow and homeConfigurations."vb@marshmallow"
├── nix/                   # Nix daemon settings (flakes, substituters, nh cleanup)
├── nixos/                 # NixOS system modules (boot, hardware, networking, services)
│   ├── default.nix        # Core system config (LUKS, power, pipewire, user)
│   ├── sway.nix           # Sway WM system-level setup
│   ├── vpn.mullvad.nix    # Mullvad VPN
│   └── ...                # greetd, ollama, syncthing, stylix
├── home/                  # Home Manager user config
│   ├── vb.nix             # Root home module (imports cli, gui, stylix, sway)
│   ├── cli/               # Shell, git, tmux, tealdeer, packages (emacs, tools)
│   ├── gui/               # foot terminal, browsers, apps, MIME types
│   ├── sway/              # Sway WM config, keybindings, idle, wlogout
│   └── stylix.nix         # Theme/color scheme (Stylix targets, overrides)
├── hosts/asus-vivobook-m3401q/  # Hardware-specific config (generated by nixos-generate-config)
└── pkgs/                  # Custom packages: wl-ocr, sway-scale-workspace
```

**Key design decisions:**
- `nixos/` = system-level (services, hardware); `home/` = user-level (programs, dotfiles)
- Stylix theme is defined entirely in `nixos/stylix.nix` (base16 scheme, fonts, cursor, image); `home/stylix.nix` simply imports it and disables specific targets (emacs, helix, hyprlock) for manual theming
- Custom packages in `pkgs/` are called via `pkgs.callPackage` in `home/cli/default.nix`
- `inputs.dev` (github:victorborzov/dev) provides custom builds of emacs, vim, helix, lf, zellij, vmrss
- Sway `package = null` is used so the system sway package is used instead of home-manager's

## Nix Style

- Use `alejandra` for formatting
- Nix linting: `nil` LSP is available
- Prefer `lib.mkOptionDefault` for extending default keybindings rather than replacing them
